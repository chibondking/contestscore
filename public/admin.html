Callsign Lookup (Busts)

Every logged QSO's callsign is checked against HamQTH to flag likely miscopies on the Possible Busts panel. If that lookup traffic itself becomes a concern mid-contest -- a busy multi-op, an upstream slowdown -- pause it here: new lookups stop immediately and whatever's already queued is dropped, not just left to drain. QSO logging and the rest of the dashboard are unaffected either way. Resuming is instant and safe any time.

Possible Busts Panel

The Possible Busts panel is for checking calls while the contest is running. Some contests forbid correcting a log from a database after the contest -- CQ WW calls it log washing (Section IX.9) and can disqualify the entry. If your club is entering one of those, or just doesn't want the list around once the contest ends, hide it here. Hidden means hidden everywhere: the dashboard and the API both stop showing the list. Lookups keep running, and showing it again is instant. This setting stays as it is after a restart or a database reset.

COSB Standings Card

Shows where this station stands on the Contest Online ScoreBoard (contestonlinescore.com) during a contest: its rank in its category, the leaders, and the stations just above and below, refreshed every 2 minutes. It appears only once COSB lists this call -- the station has to be posting there (from the logger, or with Publish below). Off unless you turn it on.

Paste the admin token above to enable this.

Publish to contestonlinescore.com

Sends this station's score to the Contest Online ScoreBoard (COSB) -- the same score your logger broadcasts, at most once every minutes. Use your COSB login (register at contestonlinescore.com first). If your logger already posts to COSB itself, leave this off. The password is kept on this server and never shown again.

Paste the admin token above to enable this.

Callsign Lookup Cache

Looked-up callsigns are kept for about six months (a "not found" result for a day) so the same calls aren't looked up again every contest. Clearing the cache forgets them all -- including the Possible Busts list -- and they're looked up afresh as they're worked. Contest data and space-weather history are not affected.

Shared server cache

The shared server cache holds lookups for every scoreboard on this server. Clearing this scoreboard's cache doesn't empty it.

Paste the admin token above to enable this.

Country File

Continent, DXCC entity and CQ zone for each worked call come from the country file (cty.csv, country-files.com). It's refreshed monthly and a new one is in use after the next deploy.
