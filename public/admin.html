Callsign Lookup (Busts)

Every logged QSO's callsign is checked against HamQTH to flag likely miscopies on the Possible Busts panel. If that lookup traffic itself becomes a concern mid-contest -- a busy multi-op, an upstream slowdown -- pause it here: new lookups stop immediately and whatever's already queued is dropped, not just left to drain. QSO logging and the rest of the dashboard are unaffected either way. Resuming is instant and safe any time.

Callsign Lookup Cache

Looked-up callsigns are kept for about six months (a "not found" result for a day) so the same calls aren't looked up again every contest. Clearing the cache forgets them all -- including the Possible Busts list -- and they're looked up afresh as they're worked. Contest data and space-weather history are not affected.

Shared server cache

The shared server cache holds lookups for every scoreboard on this server. Clearing this scoreboard's cache doesn't empty it.

Country File

Continent, DXCC entity and CQ zone for each worked call come from the country file (cty.csv, country-files.com). It's refreshed monthly and a new one is in use after the next deploy.
